YU GISANG / 유기상 INTERACTIVE CONTENT DEVELOPER

SLOGAN

아이디어를 반응하는 콘텐츠로 만듭니다.

관객의 손짓, 화면의 스크롤, 게임의 키 입력처럼 사람이 무언가를 했을 때 콘텐츠가 어떻게 반응할지를 먼저 정합니다. 시각디자인으로 시작해 웹 개발을 배웠고, Unity 게임과 프로젝션 맵핑 전시까지 작업 범위를 넓혀 왔습니다. 아이디어에 맞는 매체를 골라 직접 구현하는 것이 제 작업 방식입니다.

CAPABILITIES

  1. 01센서 입력부터 공간 출력까지 연결합니다

    졸업작품 〈LIMEN〉에서 7인 팀의 개발을 맡아 Kinect v2 바디 트래킹, 인원 추적, 인터랙션 로직, 셰이더, Spout → MadMapper 4면 출력까지 하나의 흐름으로 구성했습니다. 사용자 테스트에서 관객이 바닥 반응을 알아채지 못하는 것을 확인하고, 몸통 기준 손의 상대 속도로 손짓을 판정해 벽에서도 반응하도록 구조를 바꿨습니다.

    증명 LIMEN역량 · 인터랙티브 전시역량 · 프로젝션 맵핑

  2. 02매체에 맞는 방식으로 구현합니다

    〈SMILE PIZZA〉는 Unity 2D 미니게임 2종을 기획, 그래픽 소스, 씬 구성, 빌드까지 혼자 완성한 작업입니다. 웹에서는 〈CHROMA〉의 스크롤 전환, 〈INSIDE GISANG〉의 Matter.js 물리 인터랙션, 〈weatherUp〉의 React 상태 관리처럼 같은 아이디어도 매체에 맞는 방식을 골라 만듭니다.

    증명 SMILE PIZZACHROMAINSIDE GISANGweatherUp

  3. 03디자인과 개발을 함께 다룹니다

    시각디자인을 전공하고 디자인 국가자격 3종을 취득했습니다. 게임의 캐릭터 · 배경 · UI 소스를 Photoshop으로 직접 만들었고, 3D 웹 〈LUDIBRIUM〉에서는 Blender로 모델링한 장난감 도시를 Three.js 장면으로 옮겼습니다. 그래픽을 직접 만들기 때문에 기획 단계의 화면을 구현 단계에서 바로 맞춰 볼 수 있습니다.

    증명 LUDIBRIUM역량 · 그래픽 · 모션역량 · 3D

  4. 04전체 흐름을 보고 이끕니다

    2026년 디지털미디어디자인과 학회장으로 학회 운영과 졸업준비위원회를 총괄했습니다. 졸업작품 팀에서는 개발 전반을 책임지며 기획 · 디자인 파트와 구현 범위를 조율했습니다. 프로그래밍 윈터클래스 교안을 만들고 후배 웹 멘토링을 하며, 아는 것을 설명할 수 있는 형태로 정리하는 습관을 들였습니다.

    증명 이력서 · 활동WINTER CLASS

  5. 05빠르게 만들고 실제 환경에서 확인합니다

    작업 하나를 1~2주 단위로 끝까지 만들고, 전시 공간 · 센서 · 휴대폰에서 직접 실행해 확인합니다. 기준은 관객이 반응을 알아채는지입니다. 이 방식으로 실시간 비주얼, 기기 연동, 프로젝션 맵핑까지 다루는 매체를 넓혀 가고 있습니다.

    증명 역량 전체전체 프로젝트

DIRECTION

매체를 가리지 않고, 사람의 움직임에 반응하는 콘텐츠를 끝까지 구현하는 개발자가 되겠습니다.
