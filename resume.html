Cover Letter

매체보다 반응을 먼저 정합니다

고등학교에서 시각디자인을, 부트캠프에서 모바일 UI/UX와 Java 기반 웹 개발을 배웠고, 디지털미디어디자인과에서 Unity 게임과 프로젝션 전시까지 작업 범위를 넓혀 왔습니다. 매체는 달라도 작업마다 먼저 정하는 것은 같습니다. 사용자가 무엇을 입력하고, 화면이 언제 어떤 모양으로 반응하는지입니다. 웹에서는 스크롤과 드래그, 게임에서는 키 입력, 전시에서는 관객의 손짓이 그 입력이었습니다.

센서 입력부터 4면 출력까지 맡은 경험

졸업작품 LIMEN에서 7명 중 개발을 혼자 맡아 Kinect v2 입력, 인원 추적, 인터랙션 로직, 셰이더, Spout → MadMapper 출력까지 연결했습니다. 바닥 위치만 감지하던 첫 구조는 사용자 테스트에서 관객이 반응을 알아채지 못했고, 몸통 기준 손의 상대 속도로 손짓을 판정해 벽에서도 반응하도록 바꿨습니다. 녹화본으로 개발할 때 감지 인원이 0명으로 나온 문제는 로그에서 재생 프로세스 종료를 찾아 실행 순서를 바꿔 해결했습니다.

짧게 만들고 확인하는 방식

새 도구는 작은 결과물 하나를 끝까지 만들어 보는 것으로 익힙니다. SMILE PIZZA는 실감미디어 수업 기말에 Unity 미니게임 2종을 혼자 만들어 Windows 빌드까지 마쳤습니다. 코드 작성에 AI 도구를 함께 쓰는 작업도 결과는 미리보기 이미지, 테스트 리포트처럼 다시 확인할 수 있는 기준으로 검증하고, 설명할 수 없는 코드는 남기지 않습니다. AI가 작성하거나 보조한 범위는 작업마다 표시했습니다.

앞으로의 계획

지금 포트폴리오는 웹 작업 비중이 큽니다. 12월까지 기기 연동(OSC · UDP), TouchDesigner, 프로젝션 맵핑, Blender 에셋을 1~2주 단위 작업으로 추가하고, 2월까지 Arduino, AR, Unreal Engine으로 범위를 넓힐 계획입니다. 입사 후에는 현장 설치와 장비 연동 과정을 먼저 익히고, 기획 의도와 실제 반응 사이의 차이를 줄이는 구현을 맡고 싶습니다.
